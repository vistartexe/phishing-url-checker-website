Other observations

This is a learning project, not a security product. The model reads only the text of the URL's domain name (trained on the PhiUSIIL dataset). It does not check page content, domain age, certificates, or blocklists so "LEGITIMATE" does not mean safe.

For real decisions use your browser's Safe Browsing protection, Google Safe Browsing, or VirusTotal.
